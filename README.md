# بازارلَب — داشبورد تحلیلی بورس تهران و بورس کالا

وب‌اپلیکیشن تک‌صفحه‌ای برای اسکن نمادها، مدیریت پرتفو، اختیار معامله سهام و بورس کالا.

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس محلی Vite (معمولاً `http://127.0.0.1:5173`) را باز کنید.

ساخت نسخهٔ production:

```bash
npm run build
npm run preview
```

## ماژول‌ها

1. **دیده‌بان و Top 10** — امتیازدهی ۱۰۰‌امتیازی (فاندامنتال، پول هوشمند، تکنیکال، حمایت/مقاومت) و لیست برتر خرید
2. **تحلیل پرتفو** — سود/زیان، وزن، بتا، هشدارهای سه‌رنگ ریسک
3. **مشتقه سهام** — ارزش ذاتی/زمانی، اهرم، OI، استراتژی بر اساس IV
4. **بورس کالا** — گواهی سپرده، حباب، آربیتراژ، آتی و اختیار کالا

## ایمپورت داده

- در بخش دیده‌بان: Excel / CSV / JSON نمادها
- در بخش پرتفو: Excel با ستون‌های `نماد`، `تعداد`، `میانگین خرید`
- از دکمه‌های «قالب Excel» فایل نمونه بگیرید

اپ به‌صورت پیش‌فرض با **داده نمونه** اجرا می‌شود تا بدون اتصال API قابل استفاده باشد.

## پشته فنی

React + Vite + Tailwind CSS v4 + SheetJS (xlsx) + Lucide
